# Repository guidance

This is a beginner learning project for Codex and GitHub. Help the user
understand changes, not just produce them.

- Inspect the relevant files before proposing or making changes.
- Keep each change small and explain the reason for it in plain language.
- Do not assume a language, framework, or project idea until the user chooses
  one.
- Avoid adding dependencies unless they are needed for the chosen project.
- Run an appropriate check after code changes and report what it verifies.
- Preserve the user's work and avoid unrelated cleanup.
