# codex-learning-project

A small workspace for learning how to use Codex and GitHub together. Keep the
first changes easy to understand, review, and undo.

## Learning goals

- Give Codex a clear task and useful context.
- Review proposed changes instead of accepting them blindly.
- Run a relevant check and understand its result.
- Practice making small commits with descriptive messages.

## Working with Codex

1. Describe one small outcome, including any constraints.
2. Ask Codex to inspect the relevant files before changing them.
3. Review the diff and ask questions about anything unclear.
4. Run the suggested check and confirm the result yourself.
5. Keep or revise the change, then commit it when ready.

## Website files

- `index.html` contains the page structure and content: navigation, course
	information, the institute introduction, and the enquiry form.
- `styles.css` controls the purple-and-magenta visual design, layout, and
	responsive behavior for smaller screens.
- `script.js` powers the mobile navigation, the demo form response, and the
	automatically updated copyright year.

To try the site, open `index.html` in a web browser. The photos and web fonts
load from external services, so those details need an internet connection.
The enquiry form is a front-end demo and does not send or store submissions.
